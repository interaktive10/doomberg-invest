# F-PX (BRIEF §9): Stooq weekly CSVs, synthetic stand-ins

stooq.com resets connections from the build container (docs/SPEC_ISSUES.md 14), so these ten files are generated by
`make_px.py` (fixed seeds) in Stooq's exact format: `Date,Open,High,Low,Close,Volume`, weekly bars dated at the week's
last trading day, no Volume column for the ^spx index. `jbl.us_w.csv` carries an unadjusted 2:1 drop in week 150 for
the unconfirmed-jump test; `no_data.txt` and `limit.txt` are two answers Stooq gives instead of a CSV.

Replace them with real files where Stooq answers: `uv run python scripts/fetch_fixtures.py f-px`.
